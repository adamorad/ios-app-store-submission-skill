# React Native example

1. Install JavaScript dependencies with the repository's documented package manager.
2. Confirm the native iOS workspace and scheme used by the release build.
3. Run `scripts/preflight.sh ios` and inspect the generated Info.plist, entitlements, and privacy manifests.
4. Archive the workspace, not an unrelated project file.
5. Audit analytics, crash reporting, login, and push SDK collection before answering App Privacy.
